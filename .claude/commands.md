# My Claude Code Commands

Reference list of custom slash commands in `~/.claude/commands/` (global — available in every project). Descriptions below are pulled from each file's frontmatter `description` field — update this manually whenever you add, rename, or edit a command.

| Command | File | Description |
|---|---|---|
| `/hint` | `~/.claude/commands/hint.md` | Work through problems systematically: predict first, then get incremental hints. |
| `/read` | `~/.claude/commands/read.md` | Act as a code-reading examiner. Do NOT explain the code to me. Ask me one question at a time about this code. |
| `/debug` | `~/.claude/commands/debug.md` | Debug interactively by testing hypotheses instead of receiving an immediate fix. |
| `/explain` | `~/.claude/commands/explain.md` | Test understanding by having the learner explain a concept from memory. |
| `/api` | `~/.claude/commands/api.md` | Learn an API by investigating its purpose, assumptions, tradeoffs, and failure modes. |
| `/review` | `~/.claude/commands/review.md` | Receive an educational senior code review without an automatic rewrite. |
| `/learn` | `~/.claude/commands/learn.md` | Start a lightweight learning session and choose the right tutoring mode. |
